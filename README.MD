# Student Management System

A simple web-based Student Management System built as a full-stack CRUD application.

## Features

- Add new students
- View all students
- Edit student details
- Delete students
- Display total number of students
- Validate required fields
- Validate email addresses
- Validate phone numbers
- Prevent duplicate email addresses
- Responsive user interface
- Confirmation before deleting a student

## Technologies Used

- HTML
- CSS
- Bootstrap 5.3.3
- JavaScript
- PHP
- MariaDB
- XAMPP

## Student Details

The system stores the following information:

- Name
- Email
- Phone
- Date of Birth
- Course
- Department
- Address

## Requirements

- XAMPP
- PHP 8.2 or later
- MariaDB
- Web browser

## Installation

### 1. Install XAMPP

Install XAMPP with Apache, PHP, and MariaDB.

### 2. Clone the Repository

Place the project inside the XAMPP `htdocs` folder.
